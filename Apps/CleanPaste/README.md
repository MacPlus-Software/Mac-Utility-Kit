# CleanPaste — Demo app 1 (planned)

A native macOS menu bar text-cleanup utility. MVP: read clipboard text on request; normalize whitespace and line endings; optionally remove rich-text formatting by copying plain text; show original and cleaned previews; copy result back to clipboard.

Use shared SwiftUI foundation components rather than duplicating settings and menu bar scaffolding. Add automated tests for the pure text transformations.

**No app implemented yet.**
